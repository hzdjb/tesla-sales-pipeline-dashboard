# Data dictionary

All tables are generated by `generate_data.py` (simulated). Types are the Power Query types in `powerquery/*.m`.

## Dim_Date

**Purpose:** Calendar, one row per day 2023-01-01 to 2026-12-31. **Grain:** Day. **Rows:** 1,461. **PK:** Date. **FKs / relationships:** none.

| Column | Type | Meaning / allowed values |
|---|---|---|
| Date | Date | Primary key |
| Year | Whole number | Calendar year |
| Quarter | Text | Q1-Q4 |
| MonthNo | Whole number | 1-12 |
| MonthName | Text | Jan-Dec |
| MonthStart | Date | First day of the month |
| WeekOfYear | Whole number | ISO week |
| DayOfWeek | Text | Mon-Sun |
| IsWeekend | True/False | Saturday or Sunday |
| IsQuarterEndMonth | True/False | Mar, Jun, Sep, Dec |

## Opportunity

**Purpose:** Deals from test drive to delivery. **Grain:** Opportunity. **Rows:** 6,545. **PK:** OpportunityId. **FKs / relationships:** AccountId, StoreId, SalesRepId, SourceId, ModelId, CreatedDate, CloseDate (inactive).

| Column | Type | Meaning / allowed values |

| ModelId | Text | Foreign key |

| CloseDate | Date | Delivery date (won) or loss date; blank if open |
| IsClosed | True/False | Won or lost |

| PublicPoolDate | Date | Date released to pool |
